# 半桶庸醫 QuackCheck

耐力運動痛點自我分流與就診摘要。**痛點不是診斷。**

這個程式不判斷、不評病情等級，也不保證已知道有沒有骨折或斷裂。紅旗陰性時只提供就醫準備（香港：999／急症室）。

## 階段 1（已實作）

- 四種運動：路跑、越野、單車、三項鐵人
- 九個臨床分區（按鈕，不依賴 3D）
- 結構化痛史、紅旗三態、每區最多兩個自我檢查
- 病症方向：髑脛束、髁股關節／髁腱、阿基里斯腱中段與附著點、夾脛對骨應力、足底筋膜、深臀；下背只轉介
- 療法三層：先做／可一併試／進階了解（按摩槍、推拿、筋膜刀、磁叉）
- 本機 IndexedDB、JSON 匯出匯入、Markdown 交接摘要

## 之後

階段 2 才把同一套分區綁到 3D 肌肉模型。上肢、施治動畫與可選 AI 不在這一版。
